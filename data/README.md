# Data Sources

## D1: ITU/World Bank (CC BY-4.0)
- Mobile cellular subscriptions per 100: IT.CEL.SETS.P2
- Internet users %: IT.NET.USER.ZS
- Fixed broadband per 100: IT.NET.BBND.P2
- Source: https://data.worldbank.org/
- 25 BERM countries, 1985-2024

## D2: GSMA Mobile Connectivity Index
- 32 indicators, 173 countries
- Requires free registration: https://www.mobileconnectivityindex.com/
- Key: 2G/3G/4G/5G population coverage by country/year

## D3: RF Measurements
- Ofcom EMF measurements: https://www.ofcom.org.uk/research-and-data/telecoms-research/emf
- Academic measurement studies (see docs/integration_guides/)

## D4: Ofcom Connected Nations
- 100m x 100m grid: https://www.ofcom.org.uk/research-and-data/telecoms-research/connected-nations
- UK coverage data for microgeographic analysis

## O4: FCC Antenna Data
- ASR (Antenna Structure Registration): https://wireless2.fcc.gov/UlsApp/AsrSearch/asrRegistrationSearch.jsp
- ULS (Universal Licensing System): https://www.fcc.gov/wireless/data/public-access-files-database-downloads

## TFR/Fertility
- UN World Population Prospects: https://population.un.org/wpp/
- World Bank: SP.DYN.TFRT.IN
